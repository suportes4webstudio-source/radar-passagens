# Radar de Passagens para BH

Página com os menores preços de passagens aéreas de **São Paulo** e **Porto Alegre** para **Belo Horizonte (Confins)**, com foco nas datas mais próximas.

- `index.html`: a página
- `ofertas.json`: os dados, atualizados de hora em hora por uma tarefa agendada no Claude

Os preços são valores "a partir de" exibidos publicamente por buscadores e companhias no momento da coleta. Confirme sempre no site antes de comprar.
